# MVP scope

## P0

Home, open room, room detail, Yeb, Yeb later, I’m free, audience selection, friends, circles, room participants, room chat, temporary availability messaging, polished motion, accessibility, and demo mode.

## P1

QR friend adding, deep links, push notifications, game metadata, lightweight suggestions, detailed settings, and Supabase persistence/realtime after the local flows are excellent.

## P2 / later

Creation scarcity experiments, permanent gaming communities, nearby strangers, public discovery, public profiles, recommendation algorithms, recurrence, calendar integration, AI features, social feed, and desktop/web product.

## Guardrails

No Redux, no giant UI library, no permanent chat inbox, no public location discovery, no follower metrics, no popularity counts, no gamification. Creation limits may be abstracted behind `roomCreationPolicy` but are disabled in MVP.
